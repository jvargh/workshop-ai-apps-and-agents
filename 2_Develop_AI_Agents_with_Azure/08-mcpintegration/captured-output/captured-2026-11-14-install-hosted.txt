## Option 1: Create a Container App with a **system-assigned managed identity**

```bash
# Set variables
RG="my-containerapp-rg"
LOCATION="eastus"
ENV_NAME="my-aca-env"
APP_NAME="my-aca-app"
IMAGE="mcr.microsoft.com/azuredocs/containerapps-helloworld:latest"

# Create a resource group
az group create \
  --name "$RG" \
  --location "$LOCATION"

# Create a Container Apps environment
az containerapp env create \
  --name "$ENV_NAME" \
  --resource-group "$RG" \
  --location "$LOCATION"

# Create the Container App with a system-assigned managed identity
az containerapp create \
  --name "$APP_NAME" \
  --resource-group "$RG" \
  --environment "$ENV_NAME" \
  --image "$IMAGE" \
  --ingress external \
  --target-port 80 \
  --system-assigned
```

View the managed identity details:

```bash
az containerapp identity show \
  --name "$APP_NAME" \
  --resource-group "$RG"
```

Get the principal ID for role assignments:

```bash
PRINCIPAL_ID=$(az containerapp identity show \
  --name "$APP_NAME" \
  --resource-group "$RG" \
  --query principalId \
  --output tsv)

echo "$PRINCIPAL_ID"
```

## Option 2: Create a Container App with a **user-assigned managed identity**

```bash
# Set variables
RG="my-containerapp-rg"
LOCATION="eastus"
ENV_NAME="my-aca-env"
APP_NAME="my-aca-app"
IDENTITY_NAME="my-aca-identity"
IMAGE="mcr.microsoft.com/azuredocs/containerapps-helloworld:latest"

# Create a resource group
az group create \
  --name "$RG" \
  --location "$LOCATION"

# Create a Container Apps environment
az containerapp env create \
  --name "$ENV_NAME" \
  --resource-group "$RG" \
  --location "$LOCATION"

# Create a user-assigned managed identity
az identity create \
  --name "$IDENTITY_NAME" \
  --resource-group "$RG" \
  --location "$LOCATION"

# Get the identity resource ID
IDENTITY_ID=$(az identity show \
  --name "$IDENTITY_NAME" \
  --resource-group "$RG" \
  --query id \
  --output tsv)

# Create the Container App with the user-assigned managed identity
az containerapp create \
  --name "$APP_NAME" \
  --resource-group "$RG" \
  --environment "$ENV_NAME" \
  --image "$IMAGE" \
  --ingress external \
  --target-port 80 \
  --user-assigned "$IDENTITY_ID"
```

View the managed identity details:

```bash
az containerapp identity show \
  --name "$APP_NAME" \
  --resource-group "$RG"
```

## Optional: Assign permissions to the managed identity

A managed identity exists but has no access to other Azure resources until you grant it permissions. For example, to grant the app access to a storage account:

```bash
SCOPE="/subscriptions/<subscription-id>/resourceGroups/<resource-group>/providers/Microsoft.Storage/storageAccounts/<storage-account-name>"

az role assignment create \
  --assignee "$PRINCIPAL_ID" \
  --role "Storage Blob Data Reader" \
  --scope "$SCOPE"
```

For a user-assigned identity, use its `principalId`:

```bash
USER_ASSIGNED_PRINCIPAL_ID=$(az identity show \
  --name "$IDENTITY_NAME" \
  --resource-group "$RG" \
  --query principalId \
  --output tsv)

az role assignment create \
  --assignee "$USER_ASSIGNED_PRINCIPAL_ID" \
  --role "Storage Blob Data Reader" \
  --scope "$SCOPE"
```
